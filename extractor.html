📄 Extractor HTML

Abrí un archivo o pegá el código. Después copialo o descargalo listo para GitHub.

Cómo usarlo:
  1. Elegí el archivo .html desde tu celular, o pegá el código a mano.
  2. Copiar: lo manda al portapapeles para pegarlo directo en GitHub (editar archivo online).
  3. Descargar: guarda el archivo en tu carpeta de Descargas para subirlo con "Upload files" en GitHub.
